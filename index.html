复制用户 ID 领码激活

打开 App 首屏即「激活墨屿」页，复制「本机用户 ID」发给作者 QQ 1563475968 换取授权码，粘回同页点「激活」。详细步骤见授权码怎么获取。

导入你的书源

关于书源

使用前请花一分钟读完

墨屿是一款阅读工具，安装包内不含任何书源，也不预置任何内容站点。

请自行准备你有权使用的书源规则（.json）或订阅地址，然后在 App 内导入：

  • 书架 → 空态「导入书源文件」：本地 JSON / ZIP / TXT
  • 书源管理 → 「添加书源」：订阅地址或本地文件
  • 书源管理 → 「更新源」：可选引导，可随时取消
